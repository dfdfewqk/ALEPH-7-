### DB 레벨의 권한 실제 시험 (2026-10-19)

서버 데이터에 손상을 주지 않도록 PostgreSQL `authenticated` 역할, 테스트용 JWT claims 및 기존 활성 세션 검사를 통해 **DB 권한 정책을 직접 실행**함. UPDATE/DELETE 및 소유자 ID 변경 검사는 예외 처리 서브트랜잭션을 이용해 실제 변경사항을 모두 되돌림. 비밀번호나 JWT 원문은 사용·공개하지 않음.

| 테스트 | 결과 | 판정 |
|---|---|---|
| 유효한 세션으로 자신의 목표 SELECT | **3건** | 통과 |
| 다른 사용자 ID + 다른 사람의 `session_id`로 SELECT | **0건** | 통과 (세션 불일치 차단) |
| `sub` / `session_id` 누락 상태 SELECT | **0건** | 통과 |
| 다른 사용자 ID로 소유자의 목표 UPDATE | **0건 변경** | 통과 |
| 다른 사용자 ID로 소유자의 목표 DELETE | **0건 삭제** | 통과 |
| 소유자 자신의 목표 UPDATE | **1건 접근 허용, 이후 롤백** | 통과 |
